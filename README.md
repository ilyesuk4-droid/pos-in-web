# نظام إدارة متجر الهواتف — Mobile Shop Manager

نظام نقطة بيع وإدارة مخزون محلي (بدون اتصال بالإنترنت) لمتاجر الهواتف والإكسسوارات.

## المميزات

1. **المنتجات**: إضافة/تعديل/حذف، بحث، فلترة حسب الفئة، تنبيه المخزون المنخفض، مسح الباركود بالكاميرا، استيراد من CSV/Excel.
2. **الفئات**: إدارة فئات المنتجات.
3. **نقطة البيع (POS)**: قارئ باركود USB، مسح بالكاميرا للهواتف والويب كام، سلة مشتريات، خصم، دفع كامل/جزئي/آجل، إضافة فورية للمنتجات غير المسجلة.
4. **جرد المخزون (Inventory Count)**: مسح وتدقيق الكميات الفعلية ومقارنتها بالمخزون المسجل وتطبيق الفروقات في سجل الحركات بضغطة زر.
5. **الفواتير**: طباعة فاتورة على ورق حراري 58 أو 80 مم.
6. **العملاء والكريدي**: سجل الديون، المدفوعات، كشف الحساب.
7. **المشتريات**: تسجيل البضاعة الواردة ومسح الباركود بالكاميرا مع تحديث المخزون.
8. **حركات المخزون**: سجل كل عملية بيع وشراء وتعديل.
9. **لوحة التحكم**: إحصائيات اليوم، أفضل المبيعات، المخزون المنخفض.
10. **التقارير**: مبيعات وأرباح ومصاريف حسب فترة زمنية.
11. **المصاريف**: تتبع النفقات اليومية.
12. **ملصقات الباركود**: طباعة ملصقات Code128.
13. **الإعدادات**: خيارات ماسح الكاميرا، اختبار الماسح، اسم المتجر، الشعار، الهاتف، العنوان، فاتر الإيصال.
14. **النسخ الاحتياطي**: تصدير/استيراد كامل البيانات JSON.
15. **الإصلاحات**: إدارة طلبات الإصلاح مع تتبع الحالة والتكلفة.

## التقنيات

- **React 19** + **TanStack Start** + **TanStack Router**
- **Dexie.js** (IndexedDB) — جميع البيانات محلية بالكامل بدون خادم
- **@zxing/browser + Native BarcodeDetector API** — قراءة جميع صيغ الباركود (EAN-13, EAN-8, UPC-A, UPC-E, Code128, Code39, ITF, QR) بدون CDN محلياً بالكامل
- **PWA (Progressive Web App)** — ملف manifest و Service Worker للتثبيت على الهاتف كأنه تطبيق أصيل
- **Tailwind CSS v4** + **Radix UI**
- **TypeScript**
- دعم كامل لـ RTL، واجهة عربية وفرنسية، عملة دينار جزائري (دج)

## المسح بالكاميرا وبيئة العمل (Camera Scanner & Environment)

1. **متطلبات عمل الكاميرا (HTTPS أو Localhost)**:
   - لفتح كاميرا الهاتف أو الحاسوب، تفرض جميع متصفحات الويب الحديثة (Chrome, Safari, Firefox, Edge) بيئة آمنة (**HTTPS** أو **localhost**).
   - عند رفع المشروع على **Render** (أو أي استضافة سحابية)، يعمل الرابط بنظام HTTPS تلقائياً وتعمل الكاميرا مباشرة.
2. **تخزين البيانات لكل جهاز (Local-First IndexedDB)**:
   - يتم حفظ البيانات داخل ذاكرة المتصفح للجهاز المستخدم، مما يضمن سرعة قصوى وعملاً كاملاً دون إنترنت، وحصول كل متصفح أو جهاز على بياناته المستقلة.
3. **التثبيت على الهاتف (PWA)**:
   - يمكن فتح الرابط على متصفح الهاتف (مثل Chrome أو Safari) واختيار **"إضافة إلى الشاشة الرئيسية (Add to Home Screen)"** ليصبح تطبيقاً كاملاً على الشاشة بدون شريط عنوان المتصفح.

## تشغيل المشروع محلياً

يحتاج Node.js ≥ 18 أو Bun.

```sh
# باستخدام npm
npm install
npm run dev

# أو باستخدام bun
bun install
bun run dev
```

ثم افتح المتصفح على `http://localhost:5173`

## البناء للإنتاج والرفع على Render

```sh
# بناء النسخة الثابتة للرفع السحابي (Render Static Site)
npm run build:static

# بناء تطبيق سطح المكتب لويندوز
npm run electron:build
```
